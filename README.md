🛠️ How to Use This Repository
Because GitHub does not natively render interactive Excel dashboards in the browser, you will need to download the files to fully experience the dynamic features (like Slicers and connected pivot charts).

Click on the .xlsx file you want to view.

Click the Download raw file button (the download icon on the right side of the screen).

Open the file in Microsoft Excel. (Note: Ensure "Enable Editing" is clicked if prompted by Excel's protected view to interact with the dashboards).
